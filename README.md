🎮 لوحة تحكم مشروع التلعيب في التعليم (Gamification Dashboard)

لوحة تحكم ذكية وتفاعلية تم تطويرها باستخدام لغة البرمجة Python ومكتبات Streamlit و Plotly لتحليل بيانات استمارات الفئات الثلاث المعنية بنجاح مشروع التلعيب بالتعليم:

الطلاب الأذكياء (المرحلة الابتدائية).

أولياء الأمور.

الكادر التعليمي والتربوي (معلمين، مدراء، ومشرفين).

✨ المميزات الرئيسية للمستودع (Repository Features)

تحليل بيانات متكامل: يدمج البيانات المستخلصة من الملفات الثلاثة تلقائياً.

دعم كامل للغة العربية (RTL): واجهات مستخدم مخصصة بالكامل لضمان القراءة والعرض الصحيح للخطوط وعناصر الرسوم التفاعلية باللغة العربية.

فلاتر تصفية ذكية (Interactive Filters): إمكانية تصفية البيانات حسب الصف الدراسي للطلاب أو الدور التربوي للمعلمين بمرونة وسرعة فائقة.

كروت الأداء العام (KPI Cards): تلخص المؤشرات الأهم والجاهزية العامة لتبني المشروع مباشرة في أعلى اللوحة الرقمية.

🛠️ متطلبات التشغيل محلياً (Installation)

لتشغيل الداشبورد على جهاز الكمبيوتر الخاص بك، اتبع الخطوات البسيطة التالية:

1. تحميل الكود وتجهيز المجلد:

تأكد من وضع ملفات البيانات الثلاثة التالية في نفس مجلد الكود بعد إعادة تسميتها:

students.csv (استبيان الطلاب)

parents.csv (استبيان أولياء الأمور)

educators.csv (استبيان الكادر التعليمي)

2. تثبيت المكتبات البرمجية المطلوبة:

افتح نافذة الأوامر (Terminal/CMD) واكتب الأمر التالي:

pip install -r requirements.txt


3. تشغيل الداشبورد التفاعلي:

اكتب الأمر التالي في نافذة الأوامر لبدء تشغيل التطبيق على المتصفح الخاص بك:

streamlit run app.py


🚀 النشر على الويب بضغطة زر واحدة (Streamlit Cloud Deployment)

هذا الكود مهيأ تماماً للنشر المباشر والمجاني على الإنترنت:

ارفع الملفات الثلاثة (app.py, requirements.txt, README.md) بالإضافة لملفات الـ CSV على حسابك في GitHub.

توجه إلى موقع Streamlit Share.

اربط حسابك بجيت هاب واختر المستودع وملف app.py واضغط Deploy. ستحصل على رابط مباشر للداشبورد لمشاركته مع المدرب والجمهور فوراً!
